OverviewThe template set

Template class MyImportExport (MyImportExport - import / export any dictionary table - v1.0), family ABC and Clarion. Three templates, generated from template\win\MyImportExport.tpl and .tpw:

TemplateKindWhat it is for
MyImportExportGlobalExtensionglobal support (add once to every app)
MyImportExportButtonsControlImport / Export buttons
MyImportExportCallCodeimport / export a table

Add the global extension first: the other two require it. Every table in the dictionary is offered unless you exclude it, so a table added to the dictionary next year shows up in the window after the next generate, with no other change.

Expressions in the prompts

Start Helper program or INI file with ! to use a variable or expression instead of a literal, e.g. !GLO:DataPath & '\mie.ini'. A helper name without a folder is looked up beside the program at run time.

The generated module

The module <program>_MIE.clw holds one class bound to your dictionary, MIE_DictClass, and the two procedures that use it. Abridged from a real one:

MIE_DictClass        CLASS(MyImportExportClass),TYPE   ! one class, shared by both procedures
FM                     &FileManager
RM                     &RelationManager
Prepare                PROCEDURE                       ! helper path, INI, default format
SetupTable             PROCEDURE(STRING pName),BYTE,DERIVED
  ...                                                  ! the ABC hooks, see below
                     END

MIE_ImportExport     PROCEDURE(STRING pTable,BYTE pMode)
ThisMIE              MIE_DictClass
  CODE
  TableName = pTable
  IF TableName = '' THEN DO PickTable.                 ! small list of every offered table
  ThisMIE.Prepare()
  IF ThisMIE.SetupTable(TableName) <> 0 THEN ... RETURN 0.
  ThisMIE.LoadMap()
  Result = ThisMIE.Ask(pMode)
  ThisMIE.Kill()
  RETURN Result

MIE_ExportTables     PROCEDURE(<STRING pTables>)
ThisMIE              MIE_DictClass
  CODE
  ThisMIE.Prepare()
  ThisMIE.AddTable('Customer','Customers')             ! one per offered table
  ThisMIE.AddTable('Product','Products')
  ThisMIE.LoadTablesMap()                              ! then pTables, if given, sets the ticks
  Result = ThisMIE.AskTables()
  ThisMIE.Kill()
  RETURN Result

MIE_DictClass.SetupTable PROCEDURE(STRING pName)
  CODE
  CASE UPPER(pName)
  OF 'CUSTOMER'                                        ! Customers
    SELF.FM &= Access:Customer
    SELF.RM &= Relate:Customer
    SELF.SetTable(Customer,'Customer',CUS:KeyCustNumber)
    SELF.AddField('CUS:CustNumber','CustNumber','LONG','@n_10',CUS:CustNumber,1)
    SELF.AddField('CUS:Name','Name','STRING','@s40',CUS:Name,0)
    SELF.AddField('CUS:Phones[1]','Phones_1','STRING','@s20',CUS:Phones[1],0)
    ...
  OF 'PRODUCT'
    ...
  ELSE
    RETURN PARENT.SetupTable(pName)                    ! 1 = unknown table
  END
  RETURN 0

The ABC hooks

In an ABC app MIE_DictClass routes the table I/O through the table's FileManager and RelationManager. FM and RM are set per table in SetupTable, so the hooks need no CASE:

HookGenerated as
OpenTableFM.Open() (or RM.Open() with RelationManager deletes) + FM.UseFile(); opens and closes are counted.
CloseTableFM.Close() / RM.Close()
PrimeRecordFM.PrimeRecord() — clears the buffer and primes auto-increment
CancelPrimeFM.CancelAutoInc()
InsertRecordFM.TryInsert(); a plain ADD when the key column is mapped on an auto-increment table, so imported IDs are kept
UpdateRecordFM.TryUpdate()
FetchRecordFM.TryFetch(SELF.TableKey)
DeleteRecordFM.DeleteRecord(0) (no cascade), or RM.Delete(0) (dictionary RI)
ValidateRecord, ExportFilterYour embeds: one for any table, one per table

In a Clarion (Legacy) app only ValidateRecord and ExportFilter are generated; the class's own raw-driver hooks do the I/O.

Which fields are offered

Dictionary itemResult
A fieldOne AddField. Column name: the external NAME() if set, else the label without its prefix.
A DIM() arrayOne column per element: CUS:Phones[1] → Phones_1.
Fields inside a plain GROUPOffered one by one; the GROUP itself is not.
MEMO, BLOBNot offered.
A field declared OVER(), or anything inside an OVER or DIM groupNot offered (it would duplicate another field).
MIEEXCLUDE in a field's or GROUP's User OptionsNot offered.

ALIAS tablesLeft out: the real table is offered instead.
In-memory tables: DRIVER('MEMORY'), or declared as QUEUE / GROUPLeft out while Skip in-memory tables is ticked (the default).

The pictureThe dictionary picture; when there is none, one by type (@d10-, @t4, @s255, @n-21.2 ...).
pIsKey1 for the components of the primary key.

MIE_ExportTables

The second generated procedure exports several tables into one file: a sheet per table in XLSX and XLS, a collection per table in JSON, an element per table in XML, and a file per table for CSV and TSV. It offers every table MIE_ImportExport offers and remembers the ticked tables, the format and the file in the [MIE__Tables] INI section. Pass table labels to pre-tick them:

MIE_ExportTables()                                ! last selection
MIE_ExportTables('Customer, Product, Invoice')    ! exactly these, any case

Each table is exported with the columns, order and headers saved for it in MIE_ImportExport, and the rule embeds (ExportFilter) apply per table as usual.

Procedure's primary table is the table of the first browse on the window, else the form's table. When neither exists the user picks a table at run time. After a successful import the window is refreshed: ThisWindow.Reset(1) in ABC, which re-reads every browse.

CASE POPUP('&Import...|E&xport...')        ! one-button style
OF 1
  IF MIE_ImportExport('Customer',MIE:Mode:Import)
    ThisWindow.Reset(1)
  END
OF 2
  MIE_ImportExport('Customer',MIE:Mode:Export)
OF 3
  MIE_ExportTables()
END

RecipesMulti-DLL suites

  1. Add MyImportExportGlobal to every app. An app without it compiles its own copy of the class.
  2. In the data DLL (External: none) tick Generate MIE_ImportExport. The class is compiled in and exported, and so is the procedure.
  3. In the other DLLs and the EXE (External: all, from a DLL) leave it unticked. They import both from the data DLL — add its .LIB to their projects, as for any DLL procedure.
  4. Put MIEConvert.exe beside the EXE.

RecipesAfter a dictionary change

Regenerate the app that generates MIE_ImportExport. New tables and fields appear in the window; saved mappings for existing tables keep working, and a new field starts out ticked with its own name as the header.
