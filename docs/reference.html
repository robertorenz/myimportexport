HelperMIEConvert.exe

The class runs it for you, but it is an ordinary command-line program and can be used from scripts. Exit code 0 is success, 1 an error; the message goes to --errfile and to stderr. Its own usage text:

Usage:
  MIEConvert sheets <inputFile> <outFile> [--errfile f]
  MIEConvert import <inputFile> <outTsv> [--format f] [--sheet s] [--noheader] [--delimiter c]
                    [--encoding e] [--rowpath name] [--maxrows n] [--errfile f]
  MIEConvert export <inTsv> <outputFile> [--format f] [--sheet s] [--replacesheet] [--noheader]
                    [--delimiter c] [--encoding e] [--root name] [--row name] [--errfile f]
  MIEConvert exportmulti <listFile> <outputFile> [--format json|xml|xlsx|xls] [--root name] [--row name]
                    [--encoding e] [--noheader] [--codepage n] [--errfile f]
      listFile: one line per table: <name><TAB><MIE-TSV export file>

OptionCommandsMeaning

--replacesheetexportxlsx: keep the other sheets of an existing workbook; add or replace only --sheet.
